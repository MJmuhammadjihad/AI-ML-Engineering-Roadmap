# Security policy

Security fixes target the current code on `main`. Older downloadable editions are retained for reference and do not receive backported fixes; use the current edition when a fix is available.

## Report a vulnerability

If private vulnerability reporting is enabled, use [Report a vulnerability](https://github.com/MJmuhammadjihad/AI-ML-Engineering-Roadmap/security/advisories/new). Include the affected edition or commit, reproduction steps, expected and observed behavior, and a small example with invented data.

If that option is unavailable, use a private contact method listed on [the maintainer's profile](https://github.com/MJmuhammadjihad). If no private contact method is listed, open an issue asking for a secure reporting channel without including vulnerability details. Do not post exploits, credentials, personal progress exports, or other sensitive data in public issues.

The project has no guaranteed response time. Please allow the maintainer an opportunity to investigate and coordinate a fix before publishing exploit details.

## Local data

The learning app stores progress in the browser and supports JSON export and import. Exports may contain notes you entered; review them before sharing a bug reproduction. The app does not provide encrypted storage or account-based recovery. External learning resources have their own security and privacy policies.
