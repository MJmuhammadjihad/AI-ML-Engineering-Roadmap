# First Principles · Edition 03

An interactive AI/ML roadmap you can keep in a single HTML file. Edition 03 starts with six guided beginner days and expands into 41 modules, 205 further sessions, five career routes, four capstones, and five concept labs.

## Start learning

Download **`first-principles-atlas-v3.html`** below, then open the saved file in a modern browser. Choose **Today → Start this lesson**. No account, API key, or runtime installation is required for the app. Linked courses and resources need internet access.

Download **`first-principles-atlas-v3-source.zip`** for the editable source, build scripts, research records, tests, showcase website, and preserved editions 01/02. Use **`manifest-v3.json`** to verify the HTML hash.

## Inside this edition

- Six guided beginner days with 42 authored work blocks, runnable Python examples, and 18 misconception checks.
- A redesigned daily workspace, dedicated lesson reader, local notebook, actual-time logging, and progress export/import.
- A transfer task, rubric, repair exercise, and reviewer question for every module.
- Planning that distinguishes time spent, assisted practice, and self-reported independent evidence.
- Dated market research with explicit source and sampling limits.

The repository also includes real desktop/mobile previews, a light-themed showcase, contribution forms, continuous checks, and ready-to-adapt sharing materials. The prepared live demo requires the repository owner to enable GitHub Pages; [the setup guide](https://github.com/MJmuhammadjihad/AI-ML-Engineering-Roadmap/blob/main/docs/MAINTAINER-LAUNCH.md) lists the remaining settings.
