Before you begin

A few useful
things to know.

Read the full project guide
Do I need any experience?

No prior programming experience is assumed for the six foundation days. They include setup instructions and build from a saved file to a small command-line program. Later modules introduce more demanding software, mathematics, and ML work through prerequisites.

Can I use it offline?

The downloaded HTML contains the app, curriculum, styles, and JavaScript. It needs no runtime installation, account, or API key. Linked courses, videos, documentation, and some exercises need internet access or their own tools. For a dependable backup, export your progress: local-file storage differs between browsers.

Which paths can I explore?

Choose AI product engineering, machine learning engineering, research-oriented engineering, full-stack AI development, or the complete reference atlas. These are authored learning paths, not certifications or guarantees of a particular job.

What supports the curriculum?

The atlas includes source links, worked examples, and dated research notes. The November 4, 2026 market refresh uses nine primary-source entries and ten job descriptions from three employers. It is a targeted qualitative sample, not a representative global hiring survey. Read the research and its limits.

How can I help improve it?

Try one lesson and report the exact point that was unclear. Correct a worked example, propose a stronger practice task, or improve keyboard and mobile usability. The contribution guide explains how to get started.
